# Naming

**Decision: NeuroLog**, an internal, neurosurgery-specific operation ledger for a small group of surgeons.

## Why this name

- It says exactly what it is: a log of neurosurgical operations.
- It fits the family of the group's other tools, which use short functional names (MedScribe, DocArc).
- It works in Greek and English.

## Names considered and rejected

| Name | Why not |
| --- | --- |
| Operon | A gene unit in molecular biology; every clinician reads it as genetics. |
| Operis | Already used by an established UK financial-modelling firm. |
| SurgiLog, OpLog, SurgiTrack | Crowded niche of surgical logbook apps with near-identical names. |
| SurgiTrack, SurgiBoard | "Track" and "Board" read as surveillance of surgeons, which works against honest complication reporting. |
| TheatreLog | British spelling; reads as NHS-specific. |
| OpArc | Sibling of DocArc, but too easily confused with it. |
| Ergon (ἔργον, "work") | Distinctive and meaningful (χειρουργός = χείρ + ἔργον); kept as the alternative if the product ever grows beyond neurosurgery. |

## Tagline

*Every Case. Every Detail. One Record.*
